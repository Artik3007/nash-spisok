# Наш список 💙💗

Общий вишлист для двоих: места, фильмы, рецепты, поездки и всё, что хочется сделать вместе, чтобы ничего не забыть.

**Сайт:** https://artik3007.github.io/nash-spisok/

Всё бесплатно: сайт лежит на GitHub Pages, данные и фото хранятся в бесплатном Supabase.

---

## Что умеет приложение

- **Списки по категориям.** Сразу есть Места, Фильмы, Рецепты, Поездки и Разное. Можно создавать свои категории, переименовывать их, менять иконку и удалять.
- **Записи.** У записи есть название, адрес, заметка и фото (до 10 штук). У каждой записи статус «Хотим» или «Были». Для «Были» можно поставить оценку от 1 до 5 звёзд и дату.
- **Видно, кто добавил.** Голубая полоска и кружок с буквой — Артур, розовые — Варя.
- **«Открыть в Яндекс Картах»** — рядом с адресом.
- **«Что выбрать сегодня?»** показывает случайную запись из «Хотим». Можно выбрать категорию, нажать «Другой вариант» или сразу «Были!».
- **Напоминание на главной** появляется, если 30 дней ничего не отмечали «Были» или в «Хотим» уже 15 и больше записей.

## Как зайти

1. Откройте ссылку на сайт на телефоне.
2. **Первый человек:** «Зарегистрироваться» → почта, пароль, имя → «Создаю пару» → выбрать цвет.
3. На главной появится **код из 6 символов** (он есть и во вкладке «Профиль»). Отправьте его второй половинке.
4. **Второй человек:** «Зарегистрироваться» → почта, пароль, имя → «У меня есть код» → ввести код. Цвет назначится сам.
5. Готово: у вас общий список. Больше никто к паре присоединиться не сможет.

Дальше просто входите своей почтой и паролем. Восстановления пароля по почте в приложении нет, поэтому сохраните пароль, например, в «Пароли» на iPhone.

## Как добавить приложение на главный экран телефона

**iPhone (только через Safari):**
1. Откройте сайт в **Safari**.
2. Нажмите **«Поделиться»** (квадрат со стрелкой вверх).
3. Пролистайте вниз → **«На экран „Домой“»** → **«Добавить»**.
4. Открывайте приложение через иконку с сердечками: оно запускается на весь экран, без адресной строки, как обычное приложение.

**Android (Chrome):**
1. Откройте сайт в **Chrome**.
2. **⋮** (три точки справа вверху) → **«Добавить на главный экран»** или **«Установить приложение»**.

## Как обновлять приложение

Любое изменение в коде, отправленное на GitHub, через 1–2 минуты само появляется на сайте.

В Терминале:

```bash
cd ~/Desktop/Vishlist
git add -A
git commit -m "Что изменили"
git push
```

- Посмотреть, как идёт выкладка: GitHub → репозиторий `nash-spisok` → вкладка **Actions**. Зелёная галочка значит, что всё выложено.
- **На телефоне** новая версия подхватывается при следующем открытии. Если не подхватилась, закройте приложение полностью (смахните вверх) и откройте снова.

### Запуск на компьютере для проверки

```bash
cd ~/Desktop/Vishlist
npm run dev
```

Откройте `http://localhost:5173`. Остановить: **Ctrl+C** в Терминале.

Если вы скачали проект на новый компьютер: сначала выполните `npm install`, а файл `.env` создайте по образцу `.env.example`. Значения лежат в Supabase: Project Settings → API Keys и Data API.

## Если Supabase «заснул»

Бесплатный Supabase ставит проект на паузу, если 7 дней к нему никто не обращался.
Чтобы этого не случилось, на GitHub работает робот **«Не дать Supabase уснуть»**: примерно раз в 3 дня он делает маленький запрос в базу. Ещё он сам продлевает себе расписание, иначе GitHub выключил бы его через 60 дней без изменений в репозитории.

**Признак, что Supabase спит:** приложение пишет «Нет связи с сервером» или «Не удалось загрузить данные», хотя интернет есть.

**Что делать:**
1. Зайдите на **supabase.com** → проект `nash-spisok`.
2. Если там написано **«Project is paused»**, нажмите **«Restore project»** и подождите несколько минут. Все записи и фото сохранятся.
3. Проверьте робота: GitHub → **Actions** → слева **«Не дать Supabase уснуть»**. У последних запусков должны быть зелёные галочки.
   Если там красный крестик, нажмите **Run workflow** → **Run workflow**, чтобы запустить его вручную.
4. Если GitHub прислал письмо о том, что расписание отключено, на той же странице нажмите **Enable workflow**.

## Как устроено (для любопытных)

| Что | Где |
|---|---|
| Экраны и кнопки | `src/pages/`, `src/components/` |
| Работа с базой, фото, входом | `src/lib/` |
| База данных и правила доступа | `supabase/schema.sql` — можно запускать в Supabase → SQL Editor сколько угодно раз |
| Адрес Supabase и публичный ключ | `.env` (только на вашем компьютере) и секреты GitHub `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` |
| Роботы GitHub | `.github/workflows/deploy.yml` (выкладка сайта), `.github/workflows/keepalive.yml` (будильник) |
| Иконка приложения | `public/icon.svg`; после изменения выполните `npm run icons` |

Технологии: React, TypeScript, Vite, Tailwind, Supabase, PWA (vite-plugin-pwa), HashRouter, GitHub Pages.

## Безопасность

- В приложении используется только **публичный** ключ Supabase. Секретный ключ `service_role` не нужен нигде, никому его не давайте.
- Защита на уровне строк (RLS) включена на всех таблицах и в хранилище: записи, категории и фото видите только вы двое.
- Фото хранятся в **закрытом** хранилище. Перед загрузкой они сжимаются в телефоне (до ~300 КБ, длинная сторона до 1280 px), поэтому бесплатного места (1 ГБ) хватит на тысячи фото.
- Файл `.env` не попадает на GitHub (он в `.gitignore`).
