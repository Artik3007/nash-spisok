# Наш список 💙💗

Общий вишлист для двоих: места, фильмы, рецепты, поездки и всё, что хочется сделать вместе.

Сайт: https://artik3007.github.io/nash-spisok/

## Как зайти

1. Откройте ссылку на сайт на телефоне.
2. Первый человек: **«Зарегистрироваться»** → почта, пароль, имя → «Создаю пару» → выбрать цвет.
3. На главной появится **код из 6 символов**. Отправьте его второй половинке.
4. Второй человек: **«Зарегистрироваться»** → почта, пароль, имя → «У меня есть код» → ввести код.
5. Всё, у вас общий список. Третий человек присоединиться уже не сможет.

## Как добавить приложение на главный экран

**iPhone (только Safari):**
1. Откройте сайт в **Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Пролистайте вниз → **«На экран „Домой“»** → **«Добавить»**.
4. На экране появится иконка с сердечками. Открывайте приложение через неё: без адресной строки, как обычное приложение.

**Android (Chrome):**
1. Откройте сайт в **Chrome**.
2. Нажмите **⋮** (три точки справа вверху) → **«Добавить на главный экран»** или **«Установить приложение»**.

## Как обновлять приложение

Любое изменение в коде, отправленное на GitHub в ветку `main`, через 1–2 минуты само появляется на сайте.

```bash
cd ~/Desktop/Vishlist
git add -A
git commit -m "Что изменили"
git push
```

Посмотреть, как идёт выкладка: GitHub → репозиторий → вкладка **Actions**. Зелёная галочка значит, что всё выложено.
На телефоне новая версия подхватится при следующем открытии приложения. Если не подхватилась, закройте приложение полностью и откройте снова.

### Запуск на компьютере для проверки

```bash
cd ~/Desktop/Vishlist
npm run dev
```

Откройте `http://localhost:5173`. Остановить: **Ctrl+C**.

## Если Supabase «заснул»

Бесплатный Supabase ставит проект на паузу, если 7 дней в него никто не заходил.
Чтобы этого не было, в GitHub работает робот **«Не дать Supabase уснуть»**: раз в 3 дня он делает маленький запрос в базу.

Если приложение всё равно перестало загружать данные:
1. Зайдите на **supabase.com** → ваш проект `nash-spisok`.
2. Если там написано **«Project is paused»**, нажмите **«Restore project»** и подождите пару минут. Все данные сохранятся.
3. На GitHub → **Actions** → **«Не дать Supabase уснуть»** проверьте, что последние запуски с зелёными галочками. Если там красный крестик, нажмите **Run workflow**, чтобы запустить робота вручную.

## Где что лежит

- `src/` — код приложения (экраны, кнопки).
- `supabase/schema.sql` — база данных и правила доступа. Его можно запускать в Supabase → SQL Editor сколько угодно раз.
- `.env` — адрес проекта Supabase и публичный ключ (только на вашем компьютере, на GitHub не попадает).
- `.github/workflows/` — роботы: выкладка сайта и «будильник» для Supabase.

## Безопасность

- В приложении используется только **публичный** ключ Supabase. Секретный ключ `service_role` нигде не нужен, никому его не давайте.
- Защита на уровне строк (RLS) включена на всех таблицах и в хранилище фото: данные и фото видите только вы двое.
- Всё бесплатно: GitHub Pages, GitHub Actions и бесплатный тариф Supabase.
